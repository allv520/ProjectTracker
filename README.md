 🥗 FitTrack - Трекер питания и физической активности


## 📋 О проекте

**FitTrack** - это веб-приложение для отслеживания рациона питания и физической активности. Приложение помогает пользователям контролировать свое здоровье, предоставляя персонализированные рекомендации и детальную статистику.

**Основные возможности:**
- 📊 Учет потребляемых калорий и питательных веществ
- 🏃‍♂️ Отслеживание физической активности и тренировок
- 📈 Визуализация прогресса с помощью графиков и диаграмм
- 💡 Персонализированные рекомендации по питанию и тренировкам
- 📱 Адаптивный дизайн для всех устройств
